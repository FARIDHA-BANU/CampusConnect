
# CampusConnect — Smart Campus Event Management System

## Project Overview
CampusConnect is a web-based college event discovery and registration portal. It provides a centralized platform for students to explore events, view event details, register online, and track their registrations.

The application also includes a demonstration admin dashboard for adding, editing, deleting, and monitoring events.

## Objectives
- Simplify college event discovery.
- Provide online student registration.
- Allow students to search and filter events.
- Display event details and registration status.
- Provide a dashboard for event management.
- Reduce manual work in campus event organization.

## How to Run the Project
1. Clone or download the repository.
2. Open the CampusConnect folder in Visual Studio Code.
3. Open index.html using the Live Server extension, or open it directly in a browser.
4. Explore events and test the registration form.
5. Open the Admin Dashboard to add and manage custom events.

## Data Storage
This demonstration uses browser LocalStorage to save registrations and custom events. The data is stored locally in the current browser and is not shared across users or devices.
